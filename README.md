# Dunss AutoJersey Pro

Add-on untuk membantu proses penataan pola jersey di CorelDRAW.

## Unduh dan instal

1. Buka [halaman rilis terbaru](https://github.com/dunscreative-bit/dunss-autojerseypro-release/releases/latest).
2. Unduh `DunssAutoJerseyProSetup.exe` dari bagian **Assets**.
3. Tutup CorelDRAW, lalu jalankan installer. Jika diminta, pilih folder instalasi CorelDRAW yang sesuai.
4. Buka kembali CorelDRAW dan akses Dunss AutoJersey Pro.

## Pembaruan

Di Docker, buka tab **Lisensi** lalu pilih **Periksa update**. Untuk melihat catatan rilis dan mengunduh installer, pilih **Lihat halaman rilis**. Update tidak dipasang otomatis; unduh dan jalankan installer dari halaman rilis.

Jika pemeriksaan update dari CorelDRAW gagal, buka halaman rilis melalui browser.

## Feed informasi update

Docker membaca informasi update dari [`update.json`](https://raw.githubusercontent.com/dunscreative-bit/dunss-autojerseypro-release/main/update.json).

Saat menerbitkan versi baru, perbarui file `update.json` yang sudah ada di root branch `main`—jangan membuat salinan kedua.
